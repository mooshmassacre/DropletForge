# Changelog

## 1.0

Initial GitHub publication of DropletForge for Cinema 4D 2026.

- Native Scene Nodes surface distribution and four independently configurable droplet layers.
- Large, Medium, Small, and Micro layers with per-layer enable controls.
- Micro defaults to 3,200 droplets at 0.25 cm.
- Optional polygon Selection Tag restriction.
- Per-object droplet groups with native polygon output.
- Standard and Octane Water Drop materials with IOR 1.333 and immediate group assignment.
- Octane Object tags controlled by the saved material-engine preference.
- Persistent EN/PT-BR language and Standard/Octane preferences with a Config dialog.
- Undo/redo support and updates of earlier three-layer hierarchies.
- Lilac droplet icon with a compact F monogram.
- GPL-2.0-or-later license and English documentation.
