# DropletForge 1.0

Procedural surface droplets for Cinema 4D 2026, built with native Scene Nodes.

Generate four independent droplet layers, restrict placement with polygon Selection Tags, and assign clear-water materials for Standard or Octane. Persistent language and render-engine preferences are available through Config.

Download `DropletForge_1.0.zip`, extract it, copy the `DropletForge` folder into your Cinema 4D plugins directory, and restart Cinema 4D. Open Extensions > DropletForge.

Validated on Windows with Cinema 4D 2026.4.0. Octane support was checked with Octane 2025.4, build 1.7.2. This build uses development command ID 1000001; a plugin using the same ID will conflict. See the README and developer notes before installation.
